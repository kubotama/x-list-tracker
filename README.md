# X List Tracker

Xのリストごとに、最後に読んだポストの投稿日時を記録するアプリケーションです。

## 技術構成

- React
- TypeScript
- Vite
- Cloudflare Workers

## 動作環境

- Node.js 26

## セットアップ

依存関係をインストールします。

```bash
npm install
```

## 開発

開発サーバーを起動します。

```bash
npm run dev
```

## ビルド

本番用のビルドを実行します。

```bash
npm run build
```

## コードチェック

ESLintによる静的解析を実行します。

```bash
npm run lint
```

Prettierによるフォーマットチェックを実行します。

```bash
npm run format:check
```
